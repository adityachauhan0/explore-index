## Methodology fix applied mid-flight
The first aggregate (-32.7%) pooled cycle-001 advisory-skill runs with the
v2 binding runs. That conflates two different interventions and understates the
current design. `analyze.py` now takes `--cohort`, defaulting to `v2-binding`;
`--cohort all` keeps the full picture visible.

## The counterexample worth keeping: H1
H1 (attachment storage) is held-out with NO index row. Treatment still won
(-26.6%) but by the *smallest* margin, and its trace shows why: call 5 reads a
68KB file and call 16 saturates a grep at 100KB. When the index has nothing,
the win degrades to search discipline alone.

**This bounds the claim honestly.** The index does not make exploration free; it
removes re-derivation for topics it has covered. Covered topics save 46-58%;
uncovered topics save 17-27% purely from bounded searching.
